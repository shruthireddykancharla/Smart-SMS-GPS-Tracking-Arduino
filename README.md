# Smart SMS GPS Tracking Using Arduino

## Overview

This project implements a smart GPS tracking system using Arduino, GPS, and GSM modules. The system obtains real-time location coordinates from the GPS module and sends the location information to a user's mobile phone through SMS.

## Objective

To develop a low-cost and reliable tracking system that allows users to monitor the location of a vehicle, person, or asset using SMS-based communication.

## Components Used

* Arduino Uno
* GPS Module
* GSM Module
* Power Supply
* Connecting Wires

## Working Principle

1. The GPS module acquires the current latitude and longitude.
2. Arduino processes the GPS data.
3. The GSM module sends the location details as an SMS to a predefined mobile number.
4. The user receives the location information and can track the position.

## Features

* Real-time location tracking
* SMS-based location updates
* Low-cost implementation
* Easy to deploy and operate

## Applications

* Personal safety monitoring
* Asset tracking
* Fleet management
